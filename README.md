# DHP Status

<!--start: description-->

Uptime monitor and status page for the DHP / research-data.no services, built on [Upptime](https://upptime.js.org). Checks run every 15 minutes in GitHub Actions. Downtime opens a GitHub issue, which closes automatically on recovery. The status page is served from GitHub Pages at https://dhp-stottepakke.github.io/status.

Monitored sites are configured in [`.upptimerc.yml`](./.upptimerc.yml).
